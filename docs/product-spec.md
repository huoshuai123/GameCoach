# 雀魂 AI 复盘教练产品规格

## 定位

雀魂 AI 复盘教练是一款 Android 优先的离线复盘工具，帮助玩家从牌谱中找到真正值得复盘的关键决策点，并把每个问题转化为可理解、可训练的建议。

第一阶段目标不是判断每一手牌的绝对最优解，而是验证 AI/规则评估能否产生有教练感的复盘体验。

## 目标用户

- 想复盘但不知道从哪里看的雀魂玩家。
- 能理解基础麻将术语，但不一定有稳定复盘方法的进阶玩家。
- 愿意通过关键决策点、攻守判断和训练建议提升水平的玩家。

## 核心流程

1. 用户在 Android 端粘贴雀魂牌谱链接或雀魂牌谱屋链接。
2. 应用解析链接，识别来源、牌谱 UUID、视角标识和牌谱屋记录信息。
3. 用户点击“下载详情”，应用生成标准牌谱详情；如果是牌谱屋 `view_game` 链接，则请求牌谱屋跳转以解析官方牌谱链接。
4. 应用展示 UUID、视角标识、模式、官方牌谱链接和当前可分析状态。
5. 在完整牌谱事件流接入前，用户可用中文样例预览复盘报告样式。
6. 后续接入完整牌谱事件流后，Evaluator 从状态序列中识别 3-5 个关键决策点。

## 输入

第一阶段主入口支持链接解析：

- 雀魂牌谱链接，识别 `paipu` 中的 UUID 和视角标识。
- 雀魂牌谱屋链接，识别牌谱屋记录、模式和视角标识。
- 牌谱详情下载只做轻量标准化：普通雀魂链接直接生成详情，牌谱屋链接只解析跳转后的官方牌谱链接。
- 中文内置样例仅用于预览最终复盘报告，不作为主要导入方式。

第一阶段不做 JSON 文件导入入口。后续如果需要完整分析，应优先接入链接对应的完整牌谱事件流或受控转换服务。

## 输出

复盘报告必须包含：

- 对局基本信息。
- 局势指标。
- 3-5 个关键决策点。
- 每个决策点的巡目、玩家选择、推荐选择、问题类型、解释和训练建议。
- 面向下一局的简短训练重点。

报告结构以 `review-report-schema.md` 为准。

## 非目标

- 不做实时辅助。
- 不做账号登录。
- 不直接批量请求雀魂牌谱屋或其他第三方完整牌谱数据。
- 不做自动代打或自动操作。
- 不做 JSON 文件导入主流程。
- 不追求第一版覆盖所有役种、牌效率细节和高级押引理论。
- 不在第一阶段同时实现其他游戏。

## 成功标准

- Android Demo 能完成导入、分析、报告展示的闭环。
- 每局能稳定产出 3-5 个高价值决策点。
- 用户能从报告中知道“哪里错了、为什么、下次怎么练”。
- 领域模型和报告结构不依赖 Android UI，可迁移到其他端。
